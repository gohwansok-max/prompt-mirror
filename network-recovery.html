✓데이터 안전 상태
네트워크 오류가 발생해도 현재 브라우저에 저장된 프롬프트 기록과 커스텀 템플릿은 삭제하지 않습니다. 자동 백업은 연결이 복구되기 전까지 Drive의 기존 파일을 덮어쓰지 않습니다.
01

인터넷 연결을 확인하세요.

Wi-Fi 또는 모바일 데이터를 다시 연결한 뒤 ‘연결 다시 확인’을 누르세요. 연결이 돌아오면 Prompt Mirror의 자동 백업은 앱이 열려 있을 때 다시 점검할 수 있습니다.

02

현재 기록을 JSON 파일로 보관하세요.

기기 교체나 브라우저 초기화가 걱정될 때 사용합니다. 이 페이지는 현재 브라우저에 저장된 분석 히스토리와 커스텀 템플릿만 파일로 내보냅니다.

03

앱에서 Google Drive 동기화를 점검하세요.

연결이 돌아온 뒤 앱의 시스템 설정에서 자동 점검 또는 수동 백업을 실행하세요. Google 계정 승인이 필요하면 앱 안에서만 요청됩니다.

04

다른 기기에서 수정했다면 병합 복원을 먼저 하세요.

Drive에 바로 덮어쓰지 말고 ‘병합 복원’을 실행하면 ID와 수정 시각을 기준으로 안전하게 기록을 합칩니다. 같은 시각에 다르게 수정한 항목은 이 기기의 값을 보존합니다.
