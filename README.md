# Prompt Mirror

AI 프롬프트·대화 요약을 브라우저 안에서 분석해, 목적·맥락·제약·산출물·예시의 구성과 개선 방향을 제시하는 단일 HTML 정적 웹앱입니다.

분석 뒤에는 조사·팩트체크, 콘텐츠 작성, 문서·보고서, 코드·기능 구현, 기존 결과물 수정, 비교·의사결정, 이미지·디자인 중 목적 하나를 선택합니다. 선택 전에는 긴 템플릿을 출력하지 않으며, 선택한 목적의 모듈 하나만 공통 코어와 결합해 완성 프롬프트를 만듭니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열거나 GitHub Pages에 배포하면 됩니다. 별도 설치, 빌드, 서버, API 키가 필요하지 않습니다.

## 개인정보

분석 로직은 전부 브라우저의 JavaScript로 실행됩니다. 입력한 원문은 외부 서버로 전송하지 않습니다.
